# lfp_validation

Extracellular voltage traces of an infinitesimal electrode and of a finite spherical electrode (6 um radius) over the first 2 s of a simulation of the neocortical circuit (Supplementary Fig. 1b).

File: `lfp_infinitesimal_vs_finite.csv` (long format)

| column | description |
|---|---|
| `electrode` | `infinitesimal` or `finite` |
| `time_ms` | time since the start of the simulation (ms) |
| `voltage_V` | total extracellular signal (V) recorded by the electrode (`sumData` of `assets/validation/lookAtLFPs.ipynb`) |

Origin: generated by `assets/validation/lookAtLFPs.ipynb` (simulation of `assets/validation/`, see `ReadMe.md` there), which exports this file in its last cells.
